## How to read the coverage

- **Executed, simulated integration:** real application or middleware code and real local transport, with explicitly simulated device behavior.
- **Executed, isolated:** unit tests, mocked dependencies, or standalone native-header harnesses. These do not establish full runtime or hardware behavior.
- **Reviewed only:** documentation or source was inspected; this is not a passing test.
- **Untested, software-accessible:** a test can be developed or run without physical hardware, but was not performed here.
- **Unavailable in the current setup:** the claimed physical behavior or integration needs equipment, configuration, data, or a runtime that this setup does not currently provide.
