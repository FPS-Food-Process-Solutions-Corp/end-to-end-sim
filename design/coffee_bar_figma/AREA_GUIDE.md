# Coffee bar SVG — area groups and robot references

Drag **coffee-bar-figma.svg** into Figma. It includes the plan and a five-robot reference library on the right, at **2 px = 1 cm** throughout. Labels are vector outlines, so the Chinese and English text does not depend on installed fonts.

**robot-reference.svg** contains just the same-scale library. Select a nested **Copy / robot / equipment + both reach circles** group to copy the robot with its circles. Nova-5's package includes its cart. The parent Reference group also contains captions and dimensions if you want those.

| ME6 | 90.00 cm | 74.12 cm |

| Atom-W | 170.53 cm | 130.04 cm |

- **Orange dashed:** maximum effective diameter = 2 × (working radius + tool length).
- **Teal solid:** placement diameter = 2 × working radius × 70/85. Tool length is excluded, as confirmed.
- Tool additions: Nova-2 10 cm, Nova-5 34 cm, ME6/MG400 0 cm.
- Atom-W uses a geometric estimate from the URDF: 58.35 cm shoulder-to-hand-mount arm length + 20.60097 cm shoulder sweep around the torso axis = 78.95097 cm working radius. The palm midpoint is another 6.31633 cm from the hand mount. Fingers are excluded.
- The fixed 3.475 cm wrist-to-hand-mount adapter is counted as part of the arm, once. The palm midpoint is the centre of the palm-base mesh bounding box, excluding the separate finger meshes.
- Atom-W circles are centred on the upright torso-yaw axis, 2.5 cm behind the chassis origin. Its chassis symbol remains exactly 70 × 51 cm.
- These circles are planning envelopes, not a joint-limit or collision-free workspace simulation. Robot bodies are mounting/footprint symbols, not arm poses.

The measured breakdown is in **atom-w-reach-measurements.json**. **measure_atom_reach.py** reproduces it from the local URDF and STL.

## Grouping

The 13 top-level groups contain nested groups for each area:

- Room envelope and circulation.
- Left counter; right counter; upper shelf-strip counter; middle shelf-strip counter.
- Shelf 1 + Atom-W, with both circles inside the Atom-W package.
- Shelf 2 + Nova-5 and cart, with both circles inside the Nova-5 package.
- Coffee station → Coffee equipment → individual machines, dispensers and Nova-2 with both circles.
- Charging dock and charging zone.
- Measurements; legends; background; robot reference library.

Architectural measurements and source notes remain independent. Reference captions and cart dimensions are siblings of the reusable robot packages, so they need not be copied with the robot.

## Nova-5 cart

The cart is **60 cm across X × 80 cm down Y**, or **120 × 160 px**. The original draw.io Nova-5 mounting outline is **13 × 13 cm**, or **26 × 26 px**. Its top edge is **4 cm (8 px)** below the cart top, and its right edge is **10 cm (20 px)** left of the cart right edge. Those gaps are edge-to-edge, not centre offsets. These dimensions appear in the Nova-5 reference card.

The plan keeps the Nova-5 centre at (185, 310) cm. The cart top-left therefore becomes (141.5, 299.5) cm. Its long edge is parallel to the SVG Y-axis.

## Editable text and native Figma shapes

**coffee-bar-editable-text.svg** and **robot-reference-editable-text.svg** are alternate files with live SVG text. Figma may convert SVG text during import.

For native Figma rectangles, ellipses, lines, nested groups and editable text, use **native-figma-importer/code.js**:

1. Create a Figma Design development plugin using the Run once template.
2. Keep the manifest and plugin ID generated by Figma; replace its code.js with the supplied file.
3. Run it to create a new frame.

The importer uses Inter (or Arial) and Noto Sans SC (or Microsoft YaHei/PingFang SC). It is self-contained and makes no network requests. Its JavaScript has been syntax-checked; it has not been executed in a connected Figma editor. The SVG geometry and group hierarchy have been verified locally.

## Source assumptions and editing

The source width is 315 cm plus a separate 60 cm counter. Visible depth is 360 + 140 = 500 cm; the 575 cm annotation leaves an unconfirmed 75 cm strip. Shelf-strip lengths 60 / 100 / 100 / 100 cm are approximate. The corrected coffee-device arrangement follows the 3D scene. The charging-zone outline is inferred, while its dock uses the supplied footprint and faces left.

Edit **plan_parameters.json** to change dimensions, robot centres, device positions, reach parameters, or cart offsets. **build_plan.py** runs the current area builder. From the repository root, using a Python environment with fontTools and the bundled Node environment:

```powershell
python .\design\coffee_bar_figma\build_plan.py
node .\design\coffee_bar_figma\package_plan.cjs
node .\design\coffee_bar_figma\render_verify.cjs
```

The generator uses the local Inter and Noto Sans SC fonts to outline text. **layout-data.json** retains the complete group hierarchy and every vector. **verification.json** records the checks for circle diameters, exact scale, robot packages, cart offsets and canvas bounds.
